# Matplotlib Learning Notebooks

Jupyter notebooks documenting my Matplotlib practice, from basic plots to chart customization and plotting data with pandas.

## Notebooks

- `01_basics.ipynb` — Matplotlib basics
- `02_plot_customization.ipynb` — Plot customization
- `03_labels.ipynb` — Titles, axis labels, markers, and ticks
- `04_grid.ipynb` — Grid lines
- `05_barchart.ipynb` — Bar charts
- `06_piechart.ipynb` — Pie charts
- `07_scatter_graph.ipynb` — Scatter plots
- `09_Histogram.ipynb` — Histograms
- `10_subplot.ipynb` — Multiple plots with subplots
- `11_pandas_with_matplotlib.ipynb` — Plotting pandas data with Matplotlib

## Data file

`11_pandas_with_matplotlib.ipynb` reads `Pokemon.csv`. Keep the CSV in the same folder as the notebook, or update the notebook's file path if you store it elsewhere.

## How to use

Open the notebooks in Jupyter Notebook, JupyterLab, or Visual Studio Code. Run the cells from top to bottom. Install Python, Jupyter, Matplotlib, NumPy, and pandas if they are not already available in your environment.
